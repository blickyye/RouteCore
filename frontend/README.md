# RouteCore frontend

Статический интерфейс для существующего FastAPI API. Дополнительная сборка Node.js не нужна.

## Запуск

1. Установите зависимости бэкенда из своего `requirements.txt` (если его ещё нет, установите используемые проектом зависимости).
2. Из корневой папки проекта запустите API:

   ```bash
   uvicorn app.main:app --reload
   ```

3. Откройте `http://127.0.0.1:8000/`.
4. Swagger остаётся доступен по адресу `http://127.0.0.1:8000/docs`.

Фронтенд отдаётся тем же FastAPI-приложением, поэтому отдельная настройка CORS не требуется. Для запуска фронтенда на отдельном хосте можно до `app.js` задать `window.ROUTECORE_API_URL` и разрешить этот origin в CORS на бэкенде.

## Поддерживаемые сценарии

- Регистрация и вход через `/app/auth/registration` и `/app/auth/login`.
- Создание, просмотр и отмена заказов клиента.
- Подключение курьерского режима.
- Просмотр доступных заказов, принятие заказа и обновление статуса доставки.
- JWT хранится в `localStorage` браузера.

Интерфейс использует только существующие API-эндпоинты. Карта, расчёт стоимости и уведомления в реальном времени не реализованы.
